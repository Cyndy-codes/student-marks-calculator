Project Description

The student marks calculator is a python project developed to  calculate students academic results. It helps process subject marks and 
display the calculated results.

Objectives

To calculate students total results
To calculate students average class
To determine  grade based on marks
To practice python programming and problem solving skills.

Features

Accepts student information and subject marks
calculates total marks and average marks
determines and display grades
Saves and displays students results, where supported by  the program.

Technologies  Used

python
GitHub for source code hosting.

Concepts Applied

Variables and Data Types
User input and Output
Arithmetic Operations
Conditional Statements

How to Run

Install python on your computer.
Download the respiratory.
Open the project folder in your code or terminal
Run the main python file.
Example command:
python main.py
By replacing main.py with actual name of your python file.
